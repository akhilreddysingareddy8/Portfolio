# Singareddy Akhilreddy — Editorial Minimalist Portfolio

A responsive, editorial-style developer portfolio built with the supplied HTML structure.

## Design direction
- Warm off-white paper background with ink-black typography
- Cobalt blue and burnt-orange accents, with a soft mint hero graphic
- Editorial typography, generous whitespace, thin rules and clean grid layouts
- Responsive navigation and subtle hover interactions

## Run locally
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Files
- `index.html` — portfolio structure and content
- `style.css` — editorial minimalist responsive styling
- `assets/` — supplied artwork assets

No build step or framework is required.
